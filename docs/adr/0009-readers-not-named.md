# ADR-0009 Intended readers not named

**Context.** The work may later be shown to research, technology and public sector bodies in the UAE. Naming them in the repository could suggest a request or endorsement that does not exist, and the rules allow real names only in a context document that cites public sources read for it.

**Decision.** No intended reader is named in the repository. `docs/CONTEXT.md` names only instruments and bodies that appear in retrieved evidence table rows, with their URLs.

**Consequences.** The owner adds names, if ever, in a cover note outside the repository.
